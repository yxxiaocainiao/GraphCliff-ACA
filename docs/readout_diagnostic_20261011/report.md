# 第一轮局部读出诊断

结论：适配器两步数值自检通过；当前验证数据不足以支持“关键局部信号普遍被SAGPool丢失”的假设，不据此立即设计新支路或重跑30任务。

## 官方划分核验与用户约束

用户明确要求后续与原文划分对应。30个本地CSV逐文件核对作者旧版cf6c281与固定新版d18857db（只归一化CRLF/LF），全部内容一致；本轮graph和concat测试行ID与官方test逐项一致。此前实际拟合用的是官方train减去内部validation，二者并集与官方train一致；因此只能说train/test边界保留，不能说完整训练成员与旧版训练一致。详细30行计数见official_split_audit.csv。

本次根目录PDF为v3，第3页写明直接使用CSV预设split；它未给出30任务train/test数量表。先前提及的数量表来自v2，不能混为本地v3的明示数字。后续以经核验的作者CSV及逐行身份为准，最终拟合应使用完整官方train；若涉及内部选模和最终全train重拟合，必须先写清流程与历史协议区别，不能暗中减少训练样本或根据test挑最好epoch。

## 已完成验证

原GraphCliffRegressor与Predictor('graph')：相同初始化、同一真实训练批次、相同CUDA dropout RNG，连续两步MSE反向、clip=1、AdamW更新；预测、梯度、更新参数最大差均为0。只在内存中更新，无权重落盘。这排除了此次检查范围的适配器数值差异，不是完整训练过程或论文成绩复现。

四任务用本轮验证选出的graph权重，以原batch128回放validation。全部预测与保存CSV一致至约1e-15。最初逐分子推理未通过原2e-5阈值，改为与历史运行相同的批处理并使用只读hooks后通过，未放宽阈值。

## 观察结果

- 18对中，非MCS编辑原子平均保留率65.60%；与同分子、同度数未编辑原子作配对参照，差值-1.90个百分点，不能支持普遍特异性丢弃。
- 4个cliff对中，编辑原子平均保留率68.75%；相对同度数对照高22.64个百分点，与“cliff关键原子特别容易被删”的预期不一致，但样本太少不能否定机制。
- 18对仅5对在未加权选点后余弦差缩小，6对在实际SAGPool读出后缩小；4个cliff对分别1对、2对。全局读出和实际SAGPool还存在打分/尺度差异，余弦差改变不是信息丢失的充分证明。

## 下一步判断

不启动新读出支路训练。若继续诊断，应优先在完整官方train内部扩大结构编辑覆盖、增加匹配对照和干预，而不是查看test以增加候选或寻找好看的案例。使用拟合时见过的train分子时须标注为机制探索，并保留另一次独立验证。正式再比较concat前，应明确使用完整官方train的拟合方案和选模流程，既遵从用户要求，也避免将test选模结果当作独立测试表现。
