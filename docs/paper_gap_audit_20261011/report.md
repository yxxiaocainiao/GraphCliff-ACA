# GraphCliff原文不足、理论边界与下一步建议

输入：根目录《Kim 等 - 2025 - GraphCliff short-long range gating for modeling critical activity changes caused by subtle molecula.pdf》。共12页，首页标记arXiv:2511.03170v3，2026-08-04。页码均为PDF页序。提取文本paper_text.txt；输入SHA256与数值反例在theory_checks.json。原PDF、模型、训练代码、checkpoint、数据均未修改；本轮没有训练或发布。

## 决策

本轮已经保留官方CSV的train/test成员，不需要再次“按官方train/test划分”生成同样的划分。尚需确认的是训练集是否留出验证、早停选模、作者历史权重的确切产生流程。旧公开代码test选模与新版valid选模是两种不同协议；不能依据现在已看过的test成绩反复选择方案，再将该test称为未使用的独立验证。

建议暂停直接扩大concat。先完成纯图训练实现与官方入口的等价性核验；从下面具体缺口中挑一个做诊断，再冻结小规模多种子试验。concat保留为图+指纹的简单参照。相同协议的重新训练比较仍可回答受控机制问题，未追上论文数字不自动使比较无效，但削弱了“改进强GraphCliff基线”的说服力。

## 原文已经提出的方向：不能只靠实现就称创新

第9页第6节Limitations、以及第12页附录A.1 Directions to narrow the gap，明确建议cliff-aware contrastive/margin loss和ECFP辅助输入；作者还认为前者更值得优先尝试。因此concat和直接套用ACA都属于已有方向的实现，需要额外的方法区别、机制证据和稳定收益，才能构成贡献。此前ACA负结果不能证明所有悬崖损失无效；concat单seed约1.09% Cliff均值收益、14/30胜且Overall未改善，也不足以证明稳定改进。

## 理论问题1：连通性不足以保证非主特征值绝对值小于1

位置：第5页3.3节。原文对归一化邻接矩阵声称连通图的非主特征值绝对值均小于1，因此高次幂趋于rank-one。

反例：两个节点、一条无向边，归一化邻接A=[[0,1],[1,0]]，连通但特征值为1和-1，A的幂交替振荡。需要非二分/非周期条件或适当自环等额外假设。本地LongPoly用无自环的归一化邻接构造多项式，未显式补足这一条件；但是它使用Chebyshev组合和非线性，并非A的高次幂，所以该反例不能直接证明本地模型训练失败。

判断：谱结论的条件不完整，可明确指出；不能由此断言整个算法无效。

## 理论问题2：节点混合不推出分子间图级差异指数趋零

位置：第5页3.3节，mean-pooled cliff-pair差异O(|lambda2|^L)的结论。

即使在同一图、同一节点对齐、只有特征扰动的简化条件下，也有A^L DeltaX -> q1 q1^T DeltaX。除非DeltaX的主特征向量投影为零，通常仍存在非零极限。三角形归一化邻接满足连通、非二分，局部扰动DeltaX=(1,0,0)^T；传播深度0、1、2、10、30时mean(A^L DeltaX)都为1/3，不随深度衰减。

此外真实分子编辑可能改变邻接、原子数和节点对应，差异是A1^L X1W - A2^L X2W，不能直接套单一矩阵的谱界。纠正后的结论应把主模态残差、衰减分量、拓扑变化以及readout分开。

判断：原文无附加条件的图级趋零结论存在反例。数值检查见theory_checks.json；这不否认真实GNN的过平滑现象，也不预测其RMSE。

## 理论问题3：局部旁路存在，不等于最终预测具有局部敏感性保证

位置：第5页式(9)。导数拆分是一条链式法则关系，尚未给出旁路Jacobian非退化下界，也未排除长程项与旁路项相消。后续层仍接收已经混合的表示；一层的1-hop支路不能解释为全网络一直保留独立原始局部信号。

第4—5页SAGPool取80%节点并独立评分，随后max/mean池化和回归。即使节点差异存在，关键节点可能被删、均值可能稀释、回归头可能忽略差异。故需要考察从分子局部修改到最终预测的敏感性，而不仅是某层节点导数。

判断：证明链条不完整；实际关键节点是否被删/影响变小目前未测，属于待验证假设。

## 其他重要不足

- 第6—7页MAD/Dirichlet energy是节点内部差异，不能单独证明跨分子预测更准确。未归一化Dirichlet energy会随表示缩放c而乘c^2；需要范数控制和局部扰动对预测的直接评价。
- 第9页Table4低门控与非MCS原子重合是相关性，不能证明门控的因果作用；可设计局部节点的受控遮蔽/门控干预，与大小、度数匹配随机节点作比较。非MCS原子也不等同于唯一药理原因。
- 第12页“任何结构修改都会翻转ECFP bit”的保证过强。有限长度哈希指纹存在碰撞，有限半径/手性配置也限制可区分性；不能把ECFP当成无损监督老师。
- 第9页与第12页把剩余差距称为结构固有而非调参问题，证据不足以排除训练协议、样本量、容量等因素。当前复现差距尤其要求谨慎。

## 优先调查的机制与可行改进

优先诊断“局部信号是否在最终readout中丢失”：在development范围内，记录已知局部编辑的节点在SAGPool中保留情况、pool前后图级差异、最终预测变化，并用matched随机节点干预控制。必须使用只属于train或valid内部的分子对，不利用official test结果选机制，不跨分区挖训练对。

如果诊断支持信号丢失，再试一条浅层局部表示绕过SAGPool的读出支路，保留原GraphCliff全局支路，轻量投影融合到回归头。先保持主干、损失、学习率和参数预算受控；用参数量匹配扩头、一般多层读出等对照区分收益来源。仅增加skip/readout也并非新概念：Jumping Knowledge已学习聚合不同邻域范围，https://proceedings.mlr.press/v80/xu18c.html 。本建议是待验证研究方向，尚未完成相近工作查重，不宣称首创。

理论目标可以写为：在明确节点对齐、局部编辑、稳定pool/activation等条件下，分解编辑后输出变化，区分局部响应、长程响应和读出损失；如要给正的敏感性下界，必须明确局部Jacobian下界和其他项抵消的限制。不能因加入旁路就声称无条件保证，也不能强迫所有相似分子都大幅分离，因为非悬崖近邻应保持预测平滑。

备选机制：本地LongPoly只按无权拓扑传播，键属性只先经ShortGINE进入节点表示；可以研究键类型条件的长程传播，但并非原模型完全不用键特征，且需先确认其贡献和既有文献。当前不同时加入两个机制。

## 最小验证次序

1. 审核相同数据/seed/优化器/loader状态下官方入口与现有wrapper的首批输出、梯度和首步更新等价性，排除适配器误差。
2. 完成以上readout诊断；结果不支持则不继续该机制。
3. 冻结3—4个按train样本量选定的任务、至少3个seed及验证选模规则，对照纯图、concat、单机制。任务不得根据已看过的test收益择优。
4. 机制效应与验证收益稳定后，再固定30任务评估；已用于研究反馈的test应披露，不当作全新盲测，必要时增加独立外部验证。
