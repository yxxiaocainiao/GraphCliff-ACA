# 完整官方train内的局部读出诊断与条件性设计

## 结论

发现了“部分任务的编辑原子容易被SAGPool删去”的探索性信号，足以提出一个小规模受控候选方案；没有发现读出普遍压缩分子间差异的证据，也尚未证明删掉编辑原子是预测误差的原因。因此设计支路，但不宣称已确认机制或立即扩展30任务训练。

## 样本与边界

四任务完整官方train分别2924/503/1162/2476个分子，逐行ID断言通过；test不参与。已有graph权重仍由此前90% train拟合，未在本轮重训，不称为完成原文全train复现。140个结构近邻对通过筛选，其中18对标签差>=1，覆盖4任务。最多200结构候选/40有效对的预定上限造成抽样偏向高相似度；MCS超时/多重匹配/编辑范围的排除也有选择偏差。

这些是Morgan>=0.8诊断对，不是完整MoleculeACE三相似度定义。非MCS原子仅作为编辑位置代理，不能直接叫药理关键原子。包含训练见过的分子，配对也可能共享分子，结果不作泛化或显著性推断。

18对编辑原子平均保留49.91%；可作同度数对照的17对，其配对保留率差平均为-11.09个百分点。234方向相反，因此不能声称普遍丢弃。全部140近邻对相对对照反而高7.09个百分点，62个近等活性对的可匹配部分高13.33个百分点，提示需要区分不同局部编辑和标签差，而不能一概扩大所有邻居的表示距离。

18对中只有4对实际读出后的余弦差缩小。删除非MCS原子并不等于丢光编辑信息：信息可能已传到其他节点；余弦距离也不是预测充分性的度量。当前未做因果干预，不能从保留率直接归因到Cliff RMSE。

## 最小候选设计：浅层局部读出残差

保留原主干、SAGPool、512维回归头输入和普通MSE。读取第一层ShortGINE输出的第三个分量v^(1)，这是首次长程混合前的浅层局部特征；将全部原子的max和mean拼成512维局部读出r_local，不再经过SAGPool的节点删选。原SAGPool读出为r_graph。

    r_local = concat(max_nodes(v^(1)), mean_nodes(v^(1)))
    r_combined = r_graph + alpha * P(r_local)
    prediction = original_regression_head(r_combined)

P先固定为LayerNorm(512)->Linear(512,32)->ReLU->Linear(32,512)，约34K参数；alpha为标量并初始化0，使初始前向严格退化为原图模型。alpha=0时投影支路的首步梯度为0、alpha本身可获得梯度，这是预期行为，必须在自检中注明。支路不输入ECFP、配对标签或MCS，不改变单分子推理形式。配对只用于诊断和机制评价。

这是候选设计，不是已有实验证实的创新。max/mean仍可能稀释编辑；不能声称保留全部局部信息或对预测敏感性有无条件保证。一般多层读出/跳连已有JK-Net等方法，需查重并用具体机制与实验区分，不能只因加支路命名新算法。

## 必要对照与进一步证据

至少比较：原GraphCliff、浅层支路、相同结构/参数量但输入最终层所有节点的支路。第三组帮助区分浅层信息收益与单纯绕过SAGPool/增加参数的收益；已有concat可作参照但不能与不同训练协议混排。

正式拟合按用户要求使用完整官方train和原test成员。候选方案可采用运行前固定的100轮末checkpoint，三组相同，避免test选模；这属于明确的新固定预算比较，不能冒充论文历史早停协议。另一种是train内部选训练轮次后全train重拟合，但要显式记录流程，不能把内部验证后的90%拟合当成完整train。具体正式训练尚未启动或宣称批准了某一轮次配方。

在开始候选训练前，需验证alpha=0的输出/梯度退化、分支仅来自第一层、全train行ID和test隔离。训练后的机制证据应包含编辑位置与同度数随机位置的受控表示干预，考察预测差变化，同时报告总体RMSE与非悬崖表现，防止普遍放大局部噪声。受控表示干预本身也不等同真实化学编辑因果效应。
