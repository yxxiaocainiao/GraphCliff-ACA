# CHEMBL234 结构约束与投影先导

## 范围和待验证假设

用户建议严格结构负例、独立投影与归一化、MSE 基底及 alpha=.01。实施并完成单任务固定四组；不是已经确定因果，也不是新论文主方法。原试验代码、证据与权重保留。

预检新证据：使用训练一致float32后有440个合格有向负例对（首次float64为442），但随机首epoch只有5个三元组、82/83批空。因此训练前修订为所有四组都用相同 triad-aware batch：29普通分子+1完整三元组，普通样本每epoch一次，三元组额外重复，共91批/2905次样本。对照 MSE 也同样过采样，旧均匀采样MSE只作历史参考，不能把新采样收益算作loss收益。负例强制 T>=.8 且Δy>=1；正例仍只要求Δy<.2。最终预检：首epoch588候选、0空批，真实batch梯度比约1.00%，cosine约+.559，归一化与单分子strict加载检查通过。

停止条件：非有限值、来源/划分不符，或门控首epoch完全没有候选。随机批次候选稀疏也必须报告，不能把空项当有效监督。
